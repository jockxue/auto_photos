# FilmTone 操作逻辑问题与改造方案

审查日期：2026-11-17。基于当前 `main`（`fdb8f9a`）的代码实际行为，不是基于设计稿。

本文件只是方案，没有修改源码。

## 0. 一句话结论

App 的主要问题不是界面好不好看，而是**入口太多、每个入口走的路线不同、有几条路线走到底是死路**。

用户能从 5 个地方开始编辑一张照片，编辑器有 4 种不同的打开方式；同一个功能（选图、参考图复刻、保存）在不同页面有不同做法；还有几个按钮看起来能用、实际上什么都不做。

改造的核心是三件事：

1. **一个选图入口，一个编辑器，一种打开方式。**
2. **每个按钮要么真的做事，要么删掉。**
3. **保存只有一种语义：自动保存，返回即保存。**

## 1. 现状：用户实际会走的路线

### 1.1 进入编辑的 5 条路

| 首页入口 | 实际行为 | 问题 |
|---|---|---|
| 「一键套用预设」卡片 | `EditorView(initialTool: .filter)`，**没有传照片和项目** | 打开的是程序生成的测试图。用户调完点「保存」什么都不会存（`persist()` 遇到 `project == nil` 直接返回），导出按钮是灰的。**死路。** |
| 「一键复刻色彩」卡片 | `ColorReplicaView`，用系统 `PHPicker` 选两张图 | 选图方式和其他地方不同。走完会进入一个**直接打开「手动调色」子页**的编辑器。 |
| 「从照片中选择」 | 自定义三列多选 `PhotoSelectionView`，点「下一步」后导入 | 页面文案写「选择一张照片开始编辑」，实际是**多选**；点完「下一步」**不会进编辑器**，只是回到首页显示「已导入 N 张」。用户得自己去下面「我的项目」里找。 |
| 「照片图库」 | `PhotoManagementView`，黑底单张浏览 | 和 FilmTone 的调色主线无关。**上滑会直接删除系统相册里的照片**。点编辑每次都新建项目，同一张照片编辑两次会出现两个项目。编辑器以 **sheet** 弹出。 |
| 「我的项目」缩略图 | 编辑器以**从顶部滑入的覆盖层**打开 | 不是标准的 push 或 sheet，返回手势不可用。重命名、收藏、删除、历史版本全藏在**长按菜单**里，没有可见入口。 |

编辑器 4 种打开方式：NavigationLink push、ZStack 覆盖层、sheet、复刻页里的 navigationDestination。每种的返回方式、手势、关闭后是否刷新首页都不一样。

### 1.2 编辑器内部

底部 4 个 Tab：`预设 / 调整 / 裁剪 / 保存调色`。

- **「调整」不是 Tab**：点了不切换面板，而是 push 一个新页面 `ManualAdjustView`。和其他三个 Tab 行为不一致。
- **调整只剩 4 个参数**：曝光、鲜明度、高光、阴影。`EditState` 里其他参数（色温、对比度、饱和度、细节等）没有入口。
- **曲线工具不可达**：`Tool.curves` 和 `CurveControls` 还在代码里，但没有任何按钮能切到它。
- **「保存调色」名不副实**：里面是「选参考图」「把当前存为配方」「已保存配方列表」三件事。其中「选参考图」和首页的「一键复刻色彩」是同一个功能的第二个入口，且行为不同：
  - 首页复刻：先预览，调强度，确认后才生效。
  - 编辑器里：选完参考图**立刻以 100% 应用**，然后才出现强度滑杆和「应用配方」按钮。
  - 点已保存配方：**立刻应用**，没有预览。
  - 这个面板用的是系统 `.bordered` 按钮，视觉上和其他面板也不是一套。
- **顶栏 5 个按钮**：返回、撤销、重做、导出、保存。因为有自动保存（改动 0.4 秒后落盘），「返回」和「保存」实际效果几乎一样，但用户不知道返回会不会丢。
- **「手动调色」子页有「保存」和「完成」两个按钮**：「完成」回到编辑器；「保存」会**关掉整个编辑器**回首页。在子页里点保存却退出整个编辑，用户预期不到。
- 裁剪比例按钮没有选中态，用户看不出当前是哪个比例。

### 1.3 导出

点顶栏导出图标后：

- 页面一出现就**自动开始导出**，默认设置下还会**自动存入相册**。用户没有确认的机会。
- 存完后页面还显示「保存到相册」按钮，再点一次会**存第二份**。
- 「保存到相册」下面的说明写死为「JPEG · 高质量」，和实际设置无关。
- 导出设置不在导出页，而在「我的 → 导出设置」。用户在导出时没法改格式。
- 导出设置里有些选项是假的：
  - 选 **TIFF** 实际导出 PNG。
  - **保留 EXIF**、**保留位置** 开关存了值但导出时没有读取。
  - 「缩小尺寸」固定 2048，不能选。导出引擎支持的 4K 没有入口。
  - 导出引擎支持 HEIC，设置页里却没有这个选项。

### 1.4 一键复刻色彩

- 选两张图 → 生成预览 → 预览页可以换参考图、调强度。这一段是通的。
- 「应用色彩」：导入项目、保存，弹窗后回首页。可以。
- 「继续调整」：进入编辑器，但**直接落在「手动调色」子页**，而不是编辑器主界面。
- 复刻出来的色彩**不能存成「我的配方」**，以后想给别的照片用同一个参考效果，只能重新选参考图。
- 进入编辑器后，复刻强度已经烘焙进参数，**没法再回头调强度**。

### 1.5 「我的」

- **收藏的预设**：可以点心形收藏，但编辑器的预设列表里**没有「收藏」分组**，收藏了用不上。卡片封面是灰色占位块，副标题直接显示 `film`、`vintage` 这种代码里的 id。分类（全部 / 胶片 / 复古 / 清新）和编辑器里的分类（推荐 / 热门 / 胶片 / 自然 / 人像 / 黑白）**是两套**。
- **我的调色方案**：每张卡片上的「应用方案」**只是文字，不是按钮**，点了没反应。没有封面图，不能删除。
- 统计「收藏预设」是上面那个没用的收藏数。

## 2. 问题按严重程度排序

### P0：死路或会造成损失

1. 「一键套用预设」打开测试图，编辑结果无法保存、无法导出。
2. 「照片图库」上滑直接删除系统相册照片，且这个页面不属于调色主线。
3. 导出页自动存相册，再点「保存到相册」会重复保存。
4. 「我的调色方案」的「应用方案」不能点。
5. 导出设置里 TIFF、EXIF、位置是假选项。

### P1：路线混乱

6. 选图入口有 3 种（自定义多选页、系统 PHPicker、照片图库），编辑器打开方式有 4 种。
7. 「从照片中选择」选完不进编辑器。
8. 「调整」是 push 新页面，不是 Tab；曲线不可达；子页「保存」会退出整个编辑器。
9. 参考图复刻有两个入口、两种行为。
10. 返回 / 保存语义不清。
11. 「继续调整」落在子页而不是编辑器主界面。

### P2：体验细节

12. 项目管理全靠长按，没有可见入口。
13. 预设分类两套。
14. 收藏预设在编辑器里不可用。
15. 复刻结果不能存为配方。
16. 同一张照片多次编辑会产生重复项目。
17. 裁剪比例没有选中态。

## 3. 目标流程

### 3.1 信息架构

```
首页
├─ 开始创作
│  ├─ 套用预设 ─────→ 选择照片（单选）→ 编辑器 [预设]
│  └─ 复刻色彩 ─────→ 复刻页（选我的照片 + 参考图）→ 预览 → 编辑器 [配方] 或 直接保存
├─ 最近编辑（缩略图）→ 编辑器 [上次的 Tab]
│  └─ 右上「管理」→ 多选删除 / 收藏；单个项目「…」菜单：重命名、历史版本、删除
└─ 底部：首页 / 我的

编辑器（只有一种打开方式：NavigationStack push）
├─ 顶栏：返回（自动保存）· 撤销 · 重做 · 导出（主按钮）
├─ 预览（按住对比原图）
└─ Tab：预设 · 调整 · 裁剪 · 配方
     ├─ 预设：分类含「收藏」，长按预设可收藏，强度滑杆
     ├─ 调整：分段「光线 / 色彩 / 细节 / 曲线」，原地面板，不 push
     ├─ 裁剪：比例有选中态，旋转、翻转
     └─ 配方：「从参考图复刻」「我的配方」「存为配方」，全部先预览后应用

导出页
├─ 预览
├─ 设置摘要（格式 · 质量 · 尺寸），点开可就地修改
├─ 保存到相册（点了才存，存完变为「已保存」并禁用）
├─ 分享
└─ 完成（回到编辑器或首页）

我的
├─ 统计：作品数、配方数（收藏数仅在收藏功能接通后显示）
├─ 我的配方 → 点卡片「应用」→ 选择照片 → 编辑器 [配方，已应用]
├─ 收藏的预设 → 点卡片「使用」→ 选择照片 → 编辑器 [预设，已选中]
├─ 导出默认设置（只保留真实可用的选项）
└─ 关于
```

### 3.2 几条规则

- **选图只用一个页面**：`PhotoSelectionView`，改为支持「单选」模式。所有需要选一张照片的地方（套用预设、复刻的两个槽位、从配方/收藏进入）都走它。系统 `PHPicker` 只作为无相册权限时的后备。
- **编辑器只有一种打开方式**：`HomeView` 的 `NavigationStack` 用 `path` 驱动，定义一个路由枚举，例如：

  ```swift
  enum Route: Hashable {
      case pickPhoto(PickPurpose)
      case editor(projectID: UUID, tool: EditorView.Tool, recipeID: UUID?, presetID: String?)
      case replica
      case export(projectID: UUID)
  }
  ```

  选图完成后 `path` 里把选图页替换为编辑器页，返回时直接回首页，不会退回到选图页。
- **先导入再编辑**：任何进编辑器的路线都先变成 `PhotoProject`。导入前用 `originalAssetIdentifier` 在已有项目里查一次，已存在就直接打开，不重复导入。这一步可以在 UI 层用 `repository.allProjects()` 完成，不需要改仓库代码。
- **保存语义统一**：编辑器去掉「保存」按钮。返回时先 `await session.complete()` 再关闭，保证最后一次改动落盘、首页缩略图是新的。
- **预览后应用**：配方、参考图复刻，一律先预览、可调强度，点「应用」才写入历史。
- **假选项一律不出现**：引擎不支持的就不显示，而不是显示了不生效。

## 4. 逐页改动清单

### 4.1 首页 `HomeView.swift`

- 删除「从照片中选择」和「照片图库」两张卡片。两张创作卡就是入口。
- 「套用预设」改为 push `.pickPhoto(.preset)`，选完进编辑器。
- 「最近编辑」区标题右侧加「管理」，进入多选模式（删除、收藏）；每个缩略图加「…」按钮，内含重命名、历史版本、删除。长按菜单可以保留作为快捷方式。
- 编辑器覆盖层（`editorPayload` + `.transition(.move(edge: .top))`）去掉，改为 path push。
- 回到首页时刷新项目列表的时机统一放在 `path` 变化时。

### 4.2 选择照片 `PhotoSelectionView.swift`

- 增加 `selectionLimit` 或 `mode: .single / .multiple`。单选模式下点照片直接返回，不需要「下一步」。
- 标题和说明文案按模式区分，不再出现「选择一张」配多选。
- 完成回调返回 `PickedPhoto` 后由调用方决定去向，不在这个页面里导入。

### 4.3 编辑器 `EditorView.swift`

- 顶栏：返回 · 撤销 · 重做 · **导出**（改为文字主按钮）。删除「保存」。
- 返回：`try await session.complete()` 后再 `closeEditor()`。
- 「调整」改为真正的 Tab，原地显示面板。面板顶部分段：光线、色彩、细节、曲线。参数直接用 `AdjustmentKey` 的全部取值，曲线复用现有 `CurveControls`。`ManualAdjustView` 删除。
- 「保存调色」改名「配方」，重做 `RecipeView`：
  - 第一行三个入口：从参考图复刻、我的配方、存为配方。
  - 选参考图 / 选配方后进入**预览态**：`session.previewRecipe`，显示强度滑杆、「取消」「应用」。点「应用」才 `commitRecipe`。
  - 统一成 FilmTone 的按钮和卡片样式。
- 预设 Tab：分类里加「收藏」；长按预设缩略图切换收藏。分类定义抽成一份，和「收藏的预设」页共用。
- 裁剪比例按钮加选中态。
- `init` 增加 `initialRecipe: Recipe?`、`initialPresetID: String?`，在 `.task` 里通过现有 `commitRecipe` / `updateFilter` 应用。**不改 `EditorSession`**。

### 4.4 一键复刻 `ColorReplicaView.swift`

- 两个槽位的选图改走统一的 `PhotoSelectionView` 单选。
- 预览页底部按钮改为：「存为配方」（次要）、「去编辑」（次要）、「应用并保存」（主）。
  - 「存为配方」：把当前参考分析出的 `Recipe` 按当前强度存进 `RecipeStore`。
  - 「去编辑」：导入（或复用）项目后进入编辑器**主界面**，Tab 选「配方」，而不是 `opensAdjustments: true` 的子页。
- 重复点击「应用」不会再新建项目（现在已经用 `savedProject` 防住了，保留）。

### 4.5 导出 `ExportView.swift`

- 进入页面时**只渲染导出文件，不自动存相册**。`ExportPreferences.saveToPhotos` 这个默认项删除，或者改成「导出完成后自动保存」并在页面上明确显示「已自动保存到相册」，同时禁用「保存到相册」按钮。二选一，推荐前者。
- 「保存到相册」存完后变成「已保存」并禁用，防止重复。
- 说明文字读当前设置（格式、质量、尺寸），不写死。
- 页面上加设置摘要行，点开就地修改；修改后重新导出。
- 顶部「完成」状态只在文件真正生成后出现；失败时显示错误和「重试」。

### 4.6 我的 `ProfileView.swift`

- **导出默认设置**：删除 TIFF、保留 EXIF、保留位置三项；补上引擎支持但界面没有的 HEIC；尺寸提供 `ExportService` 真实支持的选项（原始、4K、2048）。
- **我的配方**：卡片显示配方应用在样片上的小预览（或色板）；「应用」改为真按钮 → 选择照片 → 编辑器带 `initialRecipe`；支持左滑或「…」删除。
- **收藏的预设**：封面用预设应用在一张内置样图上的效果；副标题去掉 id，改为一句描述或不显示；「使用」→ 选择照片 → 编辑器带 `initialPresetID`；分类和编辑器共用。
- 统计「收藏预设」只有在编辑器里收藏可用之后再保留。

### 4.7 照片图库 `PhotoManagementView.swift`

推荐从首页**移除入口**。理由：

- 它的定位是「浏览并删除系统照片」，和调色 App 主线无关。
- 上滑删除系统照片风险高，用户在调色 App 里不会预期这种操作。
- 它的「编辑」功能已经被统一选图页覆盖。

代码和测试可以先保留不删，等确认不需要再清理。

## 5. 实施顺序

每一步都能单独编译、单独验证、单独回退。

| 步骤 | 内容 | 主要文件 | 验收 |
|---|---|---|---|
| 1 | 堵死路：「套用预设」先选图；导出不自动存相册、存后禁用；「应用方案」先隐藏；删除导出设置里的假选项 | `HomeView`、`ExportView`、`ProfileView` | 从首页任意入口都能保存并导出；同一次导出不会存两份 |
| 2 | 统一导航：`NavigationStack(path:)` + `Route`；编辑器只走 push；选图页加单选；导入前查重 | `HomeView`、`PhotoSelectionView`、`ColorReplicaView` | 编辑器所有入口的返回行为一致；同一张照片不会出现两个项目 |
| 3 | 编辑器顶栏和保存语义：去掉「保存」，返回前 flush | `EditorView` | 改完立刻返回，首页缩略图已更新 |
| 4 | 「调整」改为原地 Tab，含光线/色彩/细节/曲线；删除 `ManualAdjustView` | `EditorView` | 所有调整参数和曲线都可达；`EditStateTests` 通过 |
| 5 | 「配方」Tab 重做为先预览后应用；复刻页加「存为配方」，「去编辑」落在编辑器主界面 | `RecipeView`、`ColorReplicaView` | 选配方不再立即生效；复刻结果能在「我的配方」看到 |
| 6 | 「我的」接通：配方应用、收藏预设、预设分类统一 | `ProfileView`、`EditorView` | 收藏的预设在编辑器里能找到；从「我的配方」能把配方用到一张新照片上 |
| 7 | 首页项目管理可见化；移除「照片图库」入口 | `HomeView` | 不用长按也能重命名、删除、查看版本 |

步骤 1 是最小止血，半天到一天能做完。做完它，App 至少不会再有「做了半天存不下来」的情况。步骤 2 是整个方案的骨架，后面的步骤都依赖它。

### 不需要改的部分

图像引擎、配方分析、渲染、导出服务、持久化、`EditorSession` 都不用动。以上改动全部在 `Features/` 下的视图层完成。唯一可能需要碰模型层的是「导入查重」，但可以先在视图层用 `allProjects()` 过滤实现。

## 6. 已确认的决定（2026-11-17）

1. **照片图库**：从首页移除入口，代码暂时保留。
2. **导出自动存相册**：保留自动存。页面明确显示「已保存到相册」，存过后「保存到相册」按钮禁用，不会重复保存。这一条覆盖 4.5 节的推荐做法。
3. **「调整」参数**：设计稿上的 4 个参数，再加一个「更多」入口展开其余参数和曲线。这一条覆盖 4.3 节的「光线/色彩/细节/曲线」分段。
4. **收藏预设**：接通到编辑器，预设分类里加「收藏」。
5. **实施范围**：先做第 1、2 步。
